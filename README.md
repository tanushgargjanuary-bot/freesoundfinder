# FreeSoundFinder 🎵

Search multiple free music and sound effect sites simultaneously with a single click.

## Features

- 🔍 **Multi-Site Search**: Opens 4 popular free asset sites at once
- 📜 **Search History**: Remembers your last 5 searches (saved locally)
- ✨ **Loading Indicator**: Visual feedback when opening sites
- 🧹 **Quick Clear**: One-click clear button for search input
- ♿ **Accessible**: Full keyboard navigation and ARIA labels
- 📱 **Responsive**: Works on desktop and mobile
- 🎨 **Dark Theme**: Easy on the eyes

## Sites Searched

| Site | Icon | Description |
|------|------|-------------|
| Pixabay Music | 🖼️ | Free royalty-free music tracks |
| Mixkit | 🎬 | Free stock music and sound effects |
| Freesound | 🔊 | Collaborative sound library |
| YouTube Audio Library | 📺 | Free music for content creators |

## How to Use

1. Open `index.html` in your browser
2. Type your search term (e.g., "lofi", "explosion", "ambient")
3. Click **Search All Sites** or press Enter
4. Four tabs will open with search results from each site
5. Click on any recent search chip to reuse it

## Quick Tips

- Press **Enter** to search quickly
- Click the **✕** button to clear your search
- Click any **recent search** to search again
- Each site opens in a new tab for easy browsing

## Tech Stack

- Pure HTML, CSS, and JavaScript (no frameworks!)
- LocalStorage for search history persistence
- SVG data URI for favicon
